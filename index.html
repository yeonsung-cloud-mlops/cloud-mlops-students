실습 전 반드시 확인

계정은 공유하지 않고, 리소스는 수업 끝에 정리합니다

보안

  • AWS 비밀번호·액세스 키·세션 토큰을 Git에 올리지 않습니다.
  • 팀원과 AWS 계정을 공유하지 않고 각자의 역할로 접속합니다.
  • 개인정보가 포함된 화면은 제출 전에 가립니다.

비용

  • 리전을 `ap-northeast-2` 서울로 확인합니다.
  • 사용 중인 EC2·SageMaker·Bedrock·ECR 리소스를 마지막 5분에 확인합니다.
  • 중지만으로 과금이 끝나지 않는 리소스는 삭제 여부를 확인합니다.

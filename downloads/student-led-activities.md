# 학생 주도 팀빌딩·주제선정 활동 안내

이 수업은 강사가 정한 순서를 그대로 따라 하는 데서 끝나지 않습니다. 팀 구성, 주제 선택, 역할 배정, 문제 해결과 검증 과정을 학생이 직접 수행하고 기록합니다.

## 1주차에 하는 일

1. 개인 역량 여권을 혼자 작성합니다.
2. 희망 역할과 경험이 한쪽에 몰리지 않도록 3~4명 팀을 만듭니다.
3. 답장·결정·지각·충돌 처리 규칙을 협상합니다.
4. 프로젝트 후보 3개를 각자 채점하고 팀 후보 2개를 정합니다.
5. 다른 팀이 후보의 실패 가능성을 질문합니다.
6. 피드백을 반영한 팀 파일 6개를 제출합니다.

## 3주차에 하는 일

후보 데이터셋을 실제로 내려받아 다음 관문을 통과해야 주제가 확정됩니다.

- 다운로드와 라이선스 확인
- 행·열·타깃 구조 확인
- 결측치·중복·이상치 확인
- 데이터 누수 가능성 설명
- 10분 이내 베이스라인 실행
- API 입력·출력 JSON 작성
- 1분 사용자 시연 설명

## 매주 반복하는 일

- 작업 담당과 완료 조건 정하기
- 막힌 문제의 증상·가설·확인 결과 기록하기
- 다른 팀원이 결과를 실행해 보기
- 결정 이유와 버린 선택 기록하기
- 커밋·파일·AWS 화면으로 개인 기여 남기기
- 비용이 발생하는 리소스 확인하기
